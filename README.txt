LB-B Personnel Dashboard
========================
1. Upload index.html and data.js to a new GitHub repository (or replace these two files in your chosen dashboard repository).
2. Settings > Pages > Deploy from a branch > main / root.
3. Open the published GitHub Pages URL.
4. When Excel data changes, regenerate data.js from the updated workbook and upload it to the repository. The Download data.js button on the dashboard exports ONLY CURRENTLY FILTERED rows, not new Excel data.
5. Source workbook and VBA remain unchanged.
6. Chart.js uses CDN internet access.
7. Personnel data may be confidential: GitHub Pages in a public repository is accessible to anyone. Do not publish without authorization.
